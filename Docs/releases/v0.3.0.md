# LuckySQL v0.3.0 — 日常工作体验升级

## 编辑与导航

- SQL 分析移出主线程，增量复用词法前缀，只为可见区域着色，行号使用索引。
- 补全复用窗口，保留候选选择，显示来源/字段类型和前缀强调；与着色共享分析缓存。
- 每个标签页独立保留撤销、光标、滚动位置；新建/切换自动聚焦。增加未保存提示、重命名、⌘W 关闭和 ⇧⌘[ / ⇧⌘] 切换。
- ⌘P 跨库快速找表，包含未展开的库，优先显示最近访问的表。
- 增加简体中文界面、开发/预发布/生产环境标识、客户端只读保护。
- 草稿持久化、文件读写、格式化和导出编码放到后台；窗口分栏、结果列布局可恢复。

## 查询与数据预览

- 查询显示执行阶段和计时；新结果到达前保留旧结果并明确标识。
- ⌘. / 取消查询通过独立连接执行 KILL QUERY，保留原连接；串行屏障避免误杀下一条查询。
- 列元数据请求合并并缓存，结构视图复用缓存；显式刷新和写入后重新获取。
- 刷新保留列宽/顺序、滚动和按主键匹配的选中行。
- 左右键切换单元格，⌘C 复制单元格，⇧⌘C 按显示列顺序复制选中行，Return/Space 打开完整值。
- 网格内只布局长值前缀，完整值按需预览。单结果最多保留 1,000 行 / 16 MiB 行负载，工作区查询预览预算 64 MiB；释放旧结果不会删除 SQL 草稿。
- 超出预算保留连续行前缀，明确显示部分预览；复制/导出只包含显示的数据，禁止对不完整预览进行网格写入。

包含上一轮 SQL 联想、在线更新和 1,000 行预览问题的修复。

## 验证与边界

- 自动化回归涵盖增量词法/Unicode、独立撤销、列布局/主键选择、后台持久化、元数据缓存、只读保护、内存预算、旧配置兼容、协议解码和更新包验证。
- 完整测试集包含 49 项（含可选真实数据库与在线更新下载测试）；无数据库/下载配置的 CI 会跳过这 3 项集成测试。
- 本机 Release 模式约 2.1 MB SQL 分析样本：完整扫描约 110 ms，缓存后的末尾编辑约 23 ms，且分析不占用 UI 主线程。这是词法分析样本，不是端到端输入延迟或所有编辑位置的保证。
- 真实 MySQL 5.6.51 / 8.4.11 验证取消后复用连接、下一条查询安全、中文/emoji、结构与大字段预算。
- 实际 macOS 窗口检查了中文界面、标签页焦点和独立撤销、旧结果保留、取消查询、未展开库快速找表。
- 仍为 macOS 14+ Apple Silicon 社区构建，ad-hoc 签名，未获 Apple 公证。
- 只读保护不是数据库权限沙箱；请使用最小权限账号。取消不能回滚已提交的写入。
- 数据负载预算不是进程 RSS 硬上限；一个超大协议包仍可能暂时占用较多内存。不是流式全库导出工具。
- 仍使用非 TLS 直连，仅用于 localhost 或可信私网；TLS/SSH、事务冲突检测和完整 HeidiSQL 功能对齐仍在路线图中。
