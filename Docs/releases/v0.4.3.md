# LuckySQL v0.4.3

This patch fixes the Restart LuckySQL button doing nothing after an update is installed.

- Dismiss the update dialog and wait until its native window is no longer modal before requesting application termination. SwiftUI's dismissal callback alone can run before that transition finishes.
- Preserve the original installation path for both installation and relaunch, even when the previous app bundle is moved to a backup.
- Prevent duplicate restart requests and recheck active operations and pending table changes before quitting. Restart failures now show an error and allow retrying.
- Stop the relaunch helper if quitting is refused, so a later manual quit does not unexpectedly reopen the app.

Validation: 110 tests passed; 18 optional or external-fixture tests were skipped. Native sheet tests cover dismissal ordering, repeated clicks, retryable failures, and operations starting during dismissal. A disposable app built with the production relaunch helper successfully exited and reopened with a new process ID; a cancelled quit did not leave a helper that reopened it later.

Upgrading from v0.4.2 or earlier: the currently running version still contains the old Restart button. If it does nothing after installing this update, close the update dialog, quit LuckySQL with Command-Q, and open it again. The fix takes effect once v0.4.3 is running.

Requirements: Apple Silicon and macOS 14 or later. Community builds use ad-hoc signing and are not notarized with Developer ID.
