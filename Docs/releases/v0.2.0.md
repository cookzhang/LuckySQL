# LuckySQL v0.2.0

面向 MySQL 日常开发的工作台更新。

## 新增功能

- SQL 语法高亮、行号、查找、基础格式化和 Ctrl-Space 补全。
- 多查询标签、草稿自动保存、查询历史、当前语句/选区/整段执行和多结果切换。
- 表数据分页、筛选、排序、完整单元格预览，以及基于主键的编辑和确认删除。
- 表结构预览：字段、索引、外键和 CREATE TABLE SQL。
- 当前结果/数据页 CSV、JSON 导出、TSV 复制，以及 SQL 文件打开和保存。
- 表搜索、收藏、EXPLAIN、进程/变量/状态查询快捷入口。

## 修复

- 修复 MySQL 5.6/5.7 协议兼容问题，数据库和表可以正常加载。
- 显式设置 utf8mb4 会话字符集，修复旧服务器上的中文和 emoji 编码问题。
- 保留空结果的列信息，正确区分 NULL 和文本，支持重复列名。
- 改善编辑器输入、滚动裁剪和钥匙串授权等待时的界面响应。

## 下载与安装

- 支持 Apple Silicon（arm64），需要 macOS 14 或更新版本。
- 下载 ZIP，解压后将 LuckySQL.app 放入 Applications。
- 此版本采用 ad-hoc 签名，尚未取得 Developer ID 签名及 Apple 公证。macOS 可能阻止首次启动；确认下载来源及 SHA-256 后，可在系统设置的“隐私与安全性”中允许打开。
- 同时提供 ZIP 的 SHA-256 校验文件。

## 验证与已知限制

- 25 项测试已分别在 MySQL 5.6.51、5.7.44、8.4.11 上通过；包含中文/emoji 字节校验。
- 当前仍是 MySQL 单连接工作台，不代表已实现 HeidiSQL 的全部功能。
- 尚不支持 TLS/SSH、可视化结构编辑器、全库导入导出及其他数据库引擎。请仅在受信任网络环境使用。
- 数据编辑直接提交；“停止并断开”不保证终止服务器查询或回滚已经发送的写入。
- SQL 结果预览最多保留 10,000 行；导出仅针对当前结果/数据页。SQL 文件最大 2 MB；批量执行最多 100 条，不支持 DELIMITER。
- 无主键表只读；二进制/生成字段禁止网格编辑。查询历史和草稿保存在本机，可能包含敏感 SQL。
- 完整差异和验收边界见 [HeidiSQL 对标文档](https://github.com/cookzhang/LuckySQL/blob/v0.2.0/Docs/HEIDISQL_PARITY.md)。
