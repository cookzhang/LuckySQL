# LuckySQL v0.4.4

This patch improves row selection and table navigation responsiveness.

- A plain click on a selected row now collapses a multiple-row selection on mouse down, before AppKit tracks a possible drag. Command-click and Shift-click keep their native selection behavior.
- Restore selected rows after refreshing data using a set lookup instead of nested comparisons, reducing work when many rows are selected.
- Reuse unchanged sidebar table rows across unrelated query updates, and build column details only while a table is expanded.

Regression coverage includes selecting one row after selecting 1,000 rows without reloading the grid, preserving selection after reordered results, and avoiding metadata loads for collapsed sidebar rows.

Requirements: Apple Silicon and macOS 14 or later. Community builds use ad-hoc signing and are not notarized with Developer ID.
