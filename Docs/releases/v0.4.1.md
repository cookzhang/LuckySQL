# LuckySQL v0.4.1

This patch fixes a freeze when quitting and gives query results more room.

- Fixed a deadlock when quitting with Command-Q. Draft encoding remains in the background, while preference writes now run on the main thread to avoid a lock cycle with SwiftUI. Removed duplicate termination saves and preserved draft recovery.
- Query results now receive about 65% of the available workspace height by default. The editor/result split remembers a proportion, so resizing the window no longer restores an oversized editor that squeezes the results.
- Added an Expand Results button with a matching Restore SQL Editor action. Drag the divider to adjust the split, or double-click it to restore the default proportion.
- Fixed empty-result layouts so the results header stays at the top of its pane.

Requirements: Apple Silicon and macOS 14 or later. Community builds use ad-hoc signing and are not notarized with Developer ID. A change in signing identity may require you to re-enter your password once.
