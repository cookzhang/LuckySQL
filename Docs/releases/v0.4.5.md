# LuckySQL v0.4.5

This patch fixes the sidebar table-list crash introduced in v0.4.4 (#36).

- Remove the EquatableView wrapper around table disclosure rows, which could trigger a SwiftUI assertion when asynchronously loaded tables appeared in the nested sidebar list.
- Keep column metadata loading on demand when a table is expanded, including cache reuse on subsequent expansions.
- Preserve the v0.4.4 fixes for selecting one row after Select All and restoring selected rows after refreshing data.

A native-window regression test covers the actual sidebar, asynchronous metadata loading, repeated expansion/collapse, and opening a context menu. The test reproduces the SwiftUI crash with the old implementation and passes with this fix. Local validation: 132 tests, 18 skipped, 0 failures.

Requirements: Apple Silicon and macOS 14 or later. Community builds use ad-hoc signing and are not notarized with Developer ID.
