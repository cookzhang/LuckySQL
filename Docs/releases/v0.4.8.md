# LuckySQL v0.4.8

This patch makes connection tabs and table selection more direct, with native sidebar selection inspired by Sequel Pro.

- Activate the saved connection when selecting a disconnected connection tab. Connected tabs retain their session and current table; missing credentials open that connection's editor directly.
- Select tables with a single click anywhere in the row or with the Up/Down keys, with native full-row highlighting. Keep the current SQL, Data, or Structure section and avoid reloading an already displayed table.
- Skip expanded column details during keyboard table navigation, retain the displayed table when collapsing its database, and synchronize highlighting when opening a table from elsewhere.
- Remove the extra Browse arrow from each table row. Explicit Data and Structure actions remain in the context menu.
- Preserve multi-row grid selections when opening a context menu. Command-C copies selected rows when more than one row is selected; Escape clears selection, and Shift-Up/Down keeps cell focus at the moving end of the range.
- Restrict Enter/Space preview to a single selected row and keep selection-wide context menus from editing or deleting an arbitrary row.

Validation: 158 tests, 139 passed, 19 optional tests skipped, and 0 failures locally, including native sidebar keyboard, context-menu, grid-selection, and connection-activation coverage.

Requirements: Apple Silicon and macOS 14 or later. Community builds use ad-hoc signing and are not notarized with Developer ID.
