# LuckySQL v0.4.0

本次版本完善 MySQL 工作台的数据一致性、远程连接、编辑与迁移工作流。

- 修复更新检查遇到 GitHub API 限流时失败的问题；备用检查继续验证官方发布包的 SHA-256、应用身份和签名完整性。
- 修复旧签名钥匙串记录不可读后，每次启动都要求重新输入密码的问题。重新输入并成功连接后，验证并保存新的钥匙串记录；不将密码写入偏好设置。
- SQL 写入后使浏览快照失效；翻页失败、筛选待应用、冲突、取消及未知提交结果有持续反馈。取消浏览和元数据请求后可继续使用原连接。
- 新增独立连接工作区、严格校验的 TLS/客户端证书和系统 SSH 隧道，以及连接与查询超时。
- 大字段默认摘要、选择列、按主键加载完整值；原始二进制用十六进制表示。大值预览分段显示，完整复制不截断。
- 新增类型/NULL 编辑、新增行、TSV 暂存与批量事务提交；InnoDB 批次失败回滚，原值冲突禁止静默覆盖。
- 新增字段、索引、外键及库表/视图/例程/触发器/事件 SQL 预览与管理。DDL 明确提示隐式提交与替换风险。
- 新增流式完整数据 CSV/JSON/SQL 导出、映射 CSV 导入及支持 DELIMITER 的大 SQL 脚本执行。
- 完善 CTE、派生表和嵌套作用域补全，新增服务器绑定参数；复合游标、前缀筛选和可复用预取连接改善远程翻页。
- 统一窗口顶部的 SQL / 数据 / 结构导航，连接标签归入右侧工作区，左侧连接树贯通；精简重复标题和留白，持久保存 SQL 字号，运行操作靠近编辑器。
- 导出列表优先显示当前数据库，支持筛选、明确勾选与选中计数；新增工作区快捷键与高级只读开关。

边界：SQL 导出是数据导出，不是完整结构备份。批量编辑使用独立事务；同一连接内 SQL 标签仍共享会话。只读保护不能替代数据库权限。完整单值加载上限 16 MiB。超长单行 SQL 仍受 TextKit 排版开销影响；不宣称与 HeidiSQL 性能等同或更快。

系统要求：Apple Silicon，macOS 14 或更新版本。社区构建采用 ad-hoc 签名，未作 Developer ID 公证；更换构建身份后可能需要重新输入一次密码。
