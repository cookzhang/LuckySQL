# LuckySQL v0.4.0

This release improves data consistency, remote connections, editing, and data migration workflows in LuckySQL’s MySQL workbench.

- Fixed update checks failing when the GitHub API rate limit is reached. The fallback still verifies the official download's SHA-256 checksum, application identity, and signature integrity.
- Fixed repeated password prompts when a Keychain entry from an older signing identity cannot be read. After you re-enter the password and connect successfully, a new Keychain entry is verified and saved. Passwords are never stored in preferences.
- Invalidate browsing snapshots after SQL writes. Persistent feedback now covers paging failures, unapplied filters, conflicts, cancellation, and unknown commit outcomes. Connections remain usable after cancelling browsing or metadata requests.
- Added independent connection workspaces, TLS with strict certificate validation and client certificate support, system SSH tunnels, and connection and query timeouts.
- Added summaries for large fields, column selection, and full-value loading by primary key. Binary values are shown as hexadecimal. Large previews are paginated, while copying the full value preserves all content.
- Added typed and NULL-aware cell editing, row insertion, TSV staging, and transactional batch commits. Failed InnoDB batches roll back, and conflicts with original values prevent silent overwrites.
- Added SQL previews and management for columns, indexes, foreign keys, databases, tables, views, routines, triggers, and events. DDL operations clearly disclose implicit commits and replacement risks.
- Added streaming exports of complete datasets to CSV, JSON, and SQL; mapped CSV imports; and execution of large SQL scripts with DELIMITER support.
- Improved completion for CTEs, derived tables, and nested scopes, and added server-bound parameters. Composite cursors, prefix filters, and reusable prefetch connections improve remote paging.
- Unified SQL / Data / Structure navigation in the window toolbar. Connection tabs now belong to the main workspace, alongside a continuous connection tree. Removed redundant headings and spacing, persisted SQL font size, and placed run controls close to the editor.
- Aligned the sidebar, search field, and status bars with the workspace. Sidebar width is remembered independently after dragging, compact windows reserve space for SQL controls, and long table names use middle truncation with full-name tooltips.
- Cell edits retain their input after explicit value or constraint errors and allow correction and retry. Unknown write outcomes, such as network interruptions, continue to block blind retries.
- Export selection prioritizes the current database and supports filtering, explicit selection, and selection counts. Added workspace keyboard shortcuts and an advanced read-only toggle.

Limitations: SQL export includes data, not a complete schema backup. Batch edits use a separate transaction; SQL tabs within the same connection still share a session. Read-only safeguards do not replace database permissions. Loading a complete individual value is limited to 16 MiB. Extremely long single-line SQL remains affected by TextKit layout overhead; no performance parity or advantage over HeidiSQL is claimed.

Requirements: Apple Silicon and macOS 14 or later. Community builds use ad-hoc signing and are not notarized with Developer ID. A change in signing identity may require you to re-enter your password once.
