# LuckySQL v0.3.1 — 更轻、更直接的连接与浏览体验

## 简单直接的连接

- “添加连接”直接在主窗口打开简洁表单，仅保留主机、端口、用户名、密码，以及可选数据库和名称；支持 ⇧⌘N。
- 移除独立设置窗口和开发／测试／生产环境配置，保留英文与简体中文界面。
- 取消编辑不修改已保存连接；无效端口在表单内提示，连接失败保留输入并支持原地重试。
- 已有连接支持直接编辑、连接和确认删除；删除最后一个连接后不再自动补回默认配置。
- 保留旧连接的只读保护以及现有 SQL 草稿。

## 更流畅的编辑与数据浏览

- 文本与光标状态按 SQL 标签页隔离，减少整个工作区的无关更新。
- SQL 分析复用未变化的词法后缀和行索引，合并连续编辑；滚动着色复用已绘制区域。
- 网格缓存显示文本和主键索引，限制大字段显示前缀，后台编码多行复制内容。
- 表浏览增加有界短期页缓存和下一页预取；单整数主键的兼容排序使用游标翻页，并保留 BIGINT 精度。
- 表搜索索引在后台规范化，输入筛选去抖，减少大量表名带来的主线程工作。

## 钥匙串不打断操作

- 密码读取、保存和删除不再请求系统交互授权；无法访问时在应用内提示。
- 安全存储不可用不再导致已成功的数据库连接被关闭，密码仅在当前进程内保留。
- 不放宽钥匙串访问权限，不使用明文密码回退，也不会自动删除或导出旧凭据。旧密码不可读取时仍需重新输入，退出后可能需要再次输入。

## 验证与边界

- 本机 Release 配置最终回归：71 项测试，70 项通过、1 项可选下载测试跳过，MySQL 5.6.51 集成验证通过。
- 本轮性能改动此前在 MySQL 5.6.51 和 8.4.11 分别完成 64 项测试（63 通过、1 跳过）；新增连接表单测试另见上述最终回归。
- 实际 macOS 窗口验证了连接表单、错误提示、取消编辑、中文／emoji 编辑、独立撤销及大 SQL 文档操作。测量细节见 `Docs/PERFORMANCE.md`；不宣称已达到 120 Hz 或端到端延迟指标。
- 浏览缓存最多 8 页／约 16 MiB，30 秒过期；显式刷新和写入会失效缓存。执行用户 SQL 后，下一页预取停用至重新连接，以保留原会话语义。
- 仍为 macOS 14+ Apple Silicon 社区构建，ad-hoc 签名，未获 Apple 公证。
- 仍为非 TLS 直连，仅适用于 localhost 或可信私网；只读保护不是数据库权限沙箱，请使用最小权限账号。
