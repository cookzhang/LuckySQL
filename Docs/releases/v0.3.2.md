# LuckySQL v0.3.2

## New app icon

- Added a charcoal and lime-green L icon, with stacked layers inspired by database rows.
- Removed the gray outer border and baked-in drop shadow for a clean, transparent edge.
- Included all standard macOS icon sizes in the app bundle for Finder and the Dock.

## Build tooling

- Added a script to regenerate the macOS icon from the source PNG.
- Updated release packaging to include and register the app icon.

## Requirements

Requires an Apple Silicon Mac running macOS 14 or later. This community build is ad-hoc signed and is not notarized by Apple.
