# LuckySQL v0.4.6

This patch improves SQL/Data navigation and sidebar table selection.

- Retain visited SQL, Data, and Structure views instead of rebuilding them on every section switch. Warm switches preserve native editors and grids, including focus, caret, selection, and scroll position.
- Keep SQL and Data result views bound to their own result snapshots while cached.
- Extend the sidebar table selection target into the blank area beside its name.
- Avoid starting column metadata requests just to select a table in SQL. Columns still load when expanding a table or browsing its data.

Native-window regression tests cover repeated section switching without grid reloads, independent result snapshots, preserved focus/selection/scroll, and clicking the blank area of a sidebar table row. Local validation: 133 tests, 18 skipped, 0 failures.

Requirements: Apple Silicon and macOS 14 or later. Community builds use ad-hoc signing and are not notarized with Developer ID.
