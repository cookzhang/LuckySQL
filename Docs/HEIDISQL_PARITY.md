# HeidiSQL 对标与产品验收

更新：2026-09-22。对照 [HeidiSQL 官方功能页](https://www.heidisql.com/screenshots.php) 和 [官方使用手册](https://www.heidisql.com/help.php)。这是功能/工作流对照，不代表已经安装、逐项实测 HeidiSQL，也不宣称完全替代。

## 已交付的 MySQL 工作台

| 工作流 | LuckySQL 当前实现 | 验收边界 |
| --- | --- | --- |
| SQL 着色 | 关键字、字符串、数字、标识符、注释独立着色 | 单一扫描器；不把字符串内的注释符误判 |
| 编辑器 | 行号、查找、撤销、基础格式化、自动关键字/库表/别名字段联想 | 自动加载引用表元数据；Ctrl-Space 触发，Tab/Return 插入；不是完整 SQL 作用域解析器 |
| 查询标签 | 独立草稿、数据库、结果集、撤销/光标/滚动；后台自动保存；重命名和快捷切换 | 一次只有一个连接；查询历史仅保存在本机；重启恢复草稿但不恢复撤销栈 |
| 执行 SQL | 当前语句、选区、整份脚本、多结果切换、EXPLAIN | 每批最多 100 条；不支持 DELIMITER/例程脚本 |
| 写入保护 | 执行前查看 SQL；非只读命令需确认 | 不等于权限沙箱；服务器账号权限仍然生效 |
| 表数据 | 点击表预览、100/200/500 行分页、筛选、服务器排序 | 主键作为稳定排序补充；无主键只读 |
| 表结构 | 字段、类型、主键、默认值、注释、索引、外键、CREATE SQL | 结构是只读预览；不冒充可视化 ALTER 设计器 |
| 数据网格 | 原生虚拟化、列布局保留、主键选中行恢复、键盘单元格导航/复制/预览 | NULL 单独标记；重复列名按位置保留；无主键按完整行值匹配 |
| 编辑数据 | 主键定位单元格更新、显式 NULL、确认删行 | 直接提交数据库；不是可撤销事务编辑器 |
| 新增数据 | 生成 INSERT 草稿，再编辑/确认执行 | 尚非可视化新增行表单 |
| 导出 | 当前结果/当前数据页 CSV、JSON、TSV 复制 | 不是全库备份；JSON 使用 columns + rows 保留重复列名 |
| SQL 文件 | UTF-8 文件打开、新标签、另存为 | 文件上限 2 MB；大脚本需流式导入工具 |
| 导航 | 已加载表搜索、收藏、最近表、⌘P 跨库找表、连接环境标识 | 快速找表会按需加载有权限的数据库；侧栏筛选仍只筛选已加载表 |
| 服务信息 | 进程、变量、状态查询快捷入口 | 不包含图形化用户权限、变量修改或终止其他会话 |
| 停止 | 独立控制连接 KILL QUERY，保留原连接；中断连接作为后备 | 服务器可能拒绝或延迟取消；不回滚之前已提交的写入 |
| 大结果 | 最多 1,000 行、单结果 16 MiB、工作区查询预览 64 MiB 负载预算 | 保留连续行前缀，超限明确提示；不是进程内存硬上限，仍需读完协议包 |
| 在线更新 | 应用内检查 GitHub、下载校验、确认安装、保留旧版备份、重启 | 需可写应用目录；GitHub HTTPS/SHA-256 信任链，不等同独立发布者签名或 Apple 公证 |

## 测试约定

- 纯逻辑：词法边界、Unicode 选区、SQL 拆分/确认、筛选转义、NULL/重复列、CSV/JSON、草稿恢复。
- 状态：表预览不覆盖草稿；修改后重查浏览 SQL；不同查询标签隔离；写入确认前不发 SQL。
- 集成：MySQL 5.6 / 5.7 / 8.4 协议回归，结构元数据、增删改、空结果、连续查询。
- UI：检查实际着色、表预览、字段/索引/DDL、过滤、单元格预览与查询标签；仅对演示数据做只读操作。
- 每轮只删除本轮创建的临时表/容器，保留现有用户库和数据。

v0.2.0 历史回归：25 项测试全部通过，分别连接 MySQL 5.6.51、5.7.44、8.4.11；中文/emoji 校验包含 HEX 字节和字符数。界面验收已发现并修复原生编辑器裁剪遮挡、只读 SQL 初始横向偏移、额外行号，以及钥匙串同步读取导致的启动阻塞。二进制/生成字段禁止网格写入，避免把显示文本写回原始字节。

实际窗口已验证：SQL 多色高亮、多标签草稿恢复、整段执行/结果集菜单、点击表读取数据、双击完整单元格预览、按字段筛选的空结果表头、字段结构与 CREATE SQL 预览；最终构建查询现有演示表中的中文姓名、多行备注和 emoji 显示正常。只读 GUI 验收未修改演示表数据。CSV/JSON 编码有单元测试，文件保存对话框尚未做端到端自动化验收；分页/排序 SQL 有单元测试，尚未对大表进行性能基准测试。
