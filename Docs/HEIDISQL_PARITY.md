# HeidiSQL 工作流对照与验收

更新：2026-09-24。本表描述当前工作分支，不表示 release 已发布。
功能对照来自 HeidiSQL 官方工作流定义；未进行同机速度对跑，不宣称比 HeidiSQL 更快。
逐 issue 的未完成验收见 [ISSUE_COMPLETION](ISSUE_COMPLETION.md)。

| 工作流 | 当前实现 | 明确边界 |
| --- | --- | --- |
| 连接 | 多个独立连接工作区、TLS CA/主机名/客户端证书、SSH、分阶段超时 | 默认六字段；高级选项折叠。SSH 严格校验 known_hosts；TLS 不降级 |
| 查询会话 | 同一连接下多个草稿共享事务/临时表；其他工作区独立 | 迁移和批量编辑使用独立会话，不提交 SQL 页的事务 |
| 编辑器 | 可调持久字号、原生查找/撤销、CTE/派生表/嵌套别名补全、绑定参数 | 容错补全解析，不是完整语法检查器；大文本原生排版基线已记录，极长单行仍有秒级开销 |
| SQL 执行 | 当前语句/选区/全批、EXPLAIN、结果切换、可取消 | 编辑器批次 100 条/文件 2 MB；大文件走 Data Transfer |
| 表浏览 | 等值/前缀/包含筛选、排序、复合 seek、缓存/预取 | contains 不承诺索引查找；无游标/缓存过期时安全 OFFSET 回退 |
| 大字段 | 所选列 + 主键投影，TEXT/BLOB 摘要，按需完整值 | 完整值上限 16 MiB；摘要禁止直接回写；原始二进制独立保存 |
| 数据编辑 | 原值冲突检查、受影响行数、键盘进入编辑、类型/NULL、新增行、TSV 暂存 | 批量仅 InnoDB；失败回滚，未知提交需人工核查；只读/无键/截断保护 |
| 结构/对象 | 字段/索引/外键 SQL 差异预览；库表、视图、例程、触发器、事件编辑 | DDL 不承诺事务回滚；生成列表达式使用 SQL 定义；替换例程明确先删后建风险 |
| 数据传输 | 完整/筛选/选定表 CSV/JSON/SQL 流式数据导出，CSV 映射导入 | SQL 文件包含数据，不是服务器/结构完整备份；多表分别写文件 |
| 大脚本 | 分块 UTF-8 解析、DELIMITER、例程、错误行号、进度/取消 | 单条语句 16 MiB；之前提交/DDL 不回滚，不自动重试非幂等语句 |
| 导航反馈 | ⌘1/2/3、⌘P、编辑器运行入口、应用中与待应用筛选、持续错误提示 | 表选择保留当前 SQL/结构工作区；显式箭头进入数据 |
| 更新 | GitHub API 限流回退官方 Releases/校验和，验证归档/身份/签名 | 所有连接工作区空闲才允许安装/重启；社区版仍为 ad-hoc 签名 |
| 密码恢复 | 旧签名无法读取时重新输入并存入新 Keychain 记录 | 不扩 ACL，不把密码放 UserDefaults；新 UUID 只在验证读取后生效 |

连接身份显示名称、主机、端口和数据库。环境标签是明确移除的产品配置，未悄悄恢复。
只读开关放在 Advanced，对新旧配置均有效；客户端保护不能替代数据库只读账号。
语言跟随 macOS 应用语言偏好，旧 AppleLanguages 覆盖继续由系统处理；不恢复 Settings 窗口。
已有英/简中资源，新增高级流程尚有英文标签。

仍不包含：PostgreSQL/SQLite 等引擎、图形化用户权限管理、Apple Developer ID 公证、独立发布者更新签名。它们不作为本轮 MySQL issues 已实现能力宣传。

测试只操作独立临时库表/容器。真实数据库矩阵已覆盖 MySQL 5.6/5.7/8.4 与 MariaDB 11.4，其后的导航与导出界面更改通过 30 项回归和两种尺寸的原生布局检查。截图、延迟分布及每项发布验收以完成台账和性能报告为准，不能以纯逻辑测试替代原生工作流验证。
